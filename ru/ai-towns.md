# ИИ: строительство и найм в городах
{: .no_toc }

1. TOC
{:toc}

## Коротко

- У каждой постройки есть **прямая ценность**. Она есть только у доходных зданий, жилищ, укреплений, зданий прироста и нескольких особых построек.
- Постройка оценивается как `ценность × 1000 / стоимость`, где в стоимость входят **все ещё не построенные предпосылки**, а считается она через [веса ресурсов](../ai-adventure/#сколько-стоят-ресурсы).
- Оценка цели приписывается каждой постройке в её цепочке предпосылок, и побеждает лучшая из тех, что можно построить сегодня.
- У Гильдий магов, Рынка, Таверны и Кузницы прямой ценности нет; в этой функции они строятся только как предпосылки. Гильдии магов и Кузница строятся ещё и [при визите героя](#когда-герой-заходит-в-свой-город).
- На лёгкой и нормальной сложности город компьютерного игрока строит не чаще чем **раз в два дня**.

## Экономическая часть хода

Номера, стоимость и предпосылки построек приведены в главе [Фракции и города](../towns/). Три новых города HotA не охвачены ([что известно](../hota/)).

`0x428dd0`, один раз за ход для каждого компьютерного игрока:

1. Повторять `0x42ae00`, пока находится что купить. Каждый вызов строит одну постройку.
2. Решить, нанимать ли героя (`0x431360`, см. [наём героев](../ai-adventure/#наём-героев)).
3. Пересчитать веса ресурсов (`0x428740`).
4. Если у игрока есть город с Рынком, отправить избыток ресурсов союзникам (`0x429110`, см. [подарки](#подарки-союзникам)).

## Одна постройка на город в день или в два дня

`0x5bede0` ставит на городе отметку, когда в нём что-то построено; `0x4c7fe0` снимает её в начале каждого дня.

| Сложность | Отметка после постройки | Итог |
|---|---|---|
| Высокая, экспертная, невозможная | снимается каждый день | одна постройка на город в день |
| Лёгкая, нормальная | ставится в 2 и уменьшается на 1 в день для города компьютерного игрока | **одна постройка на город раз в два дня** |

## Прямая ценность постройки

`0x42ae00`. Номера построек внутренние (0–43).

| Постройка | Прямая ценность | Функция |
|---|---|---|
| Линия Ратуши (10–13) | Добавочное недельное золото × вес золота: Сельская управа 3500, Ратуша 3500, Магистрат 7000, Капитолий 14000 | `0x42b8b0` |
| Жилища (30–36) | Только когда на городе нет отметки угрозы. `AI Value × недельный прирост` существа. С 5-го дня недели прирост удваивается и добавляются уже ждущие существа. Стоимость их покупки добавляется к стороне затрат | `0x42b520` |
| Улучшенные жилища (37–43) | Своя функция, та же идея | `0x42b5b0` |
| Цитадель, Замок (8, 9) | С 5-го дня: сумма AI Value существ города, у которых будет прирост, а стоимость их покупки идёт в затраты | `0x42b670` |
| Здания прироста (18, 19, 24, 25) | Свои функции | `0x42b790`, `0x42b800` |
| Хранилище ресурсов (15) | Семь дней его выработки по весам ресурсов; не когда на городе стоит отметка угрозы | |
| Сокровищница Оплота (22) | Только на 7-й день; пропорционально золоту игрока | |
| Башня: особая постройка 21 | 100 | |
| Некрополис: особая постройка 17 | 10 | |
| Некрополис: особая постройка 21 | Растёт с числом героев игрока одного определённого класса | |
| Цитадель (город): особая постройка 17 | 5000, только когда на городе стоит отметка угрозы и в нём есть гостящий герой | |
| Крепость: особые постройки 21, 22 | Сумма `AI Value` гарнизона / 20, только когда на городе стоит отметка угрозы | |

Если условие победы сценария — построить в этом городе Ратушу или Форт заданного уровня, соответствующие постройки получают +5 000 000.

## Оценка и выбор

Для каждой постройки с положительной прямой ценностью:

1. Собрать её недостающие предпосылки из таблицы зависимостей типа города (`0x697798`).
2. Сложить стоимости всей цепочки.
3. `оценка = ценность × 1000 / Σ (стоимость[r] × вес[r])` (`0x42a150`). Если нужный ресурс нечем оплатить и у игрока нет его дохода, проверяется, можно ли получить его обменом; если нет, цель отбрасывается.
4. Прибавить оценку **каждой постройке в цепочке**.

Затем среди всех городов игрока, которым сегодня ещё можно строить, строится доступная постройка с наибольшей накопленной оценкой, при условии что у игрока остаётся резерв, который функция придерживает на запланированные покупки. Проверка резерва не делается для линии Ратуши, Рынка и Хранилища ресурсов. **[code]**

Дешёвая постройка, открывающая несколько ценных, собирает все их оценки; так строятся Гильдия магов 1-го уровня, Кузница или Рынок, хотя своей ценности у них нет.

## Каких существ покупают первыми

`0x42d690` и `0x42d420`, используются при любом найме ИИ: для гостящего героя, для гарнизона и при экстренной закупке, когда город в опасности.

1. Сначала в принимающей армии объединяются отряды одного существа, чтобы освободить слоты.
2. Для каждого доступного существа считается, сколько можно оплатить: меньшее из доступного числа и того, что позволяет каждый ресурс.
3. Считается **выигрыш** от добавления стольких существ в эту армию (`0x42c830`; она учитывает свободные слоты и отряды, которые пришлось бы вытеснить).
4. Когда покупка идёт в счёт планов игрока, вычитается её стоимость по [весам ресурсов](../ai-adventure/#сколько-стоят-ресурсы), но не больше трёх четвертей выигрыша.
5. Покупается вариант с наибольшим результатом, после чего всё повторяется с шага 2, пока есть варианты с положительным результатом.

То есть порядок не «сначала старший уровень»: покупается то, что в данный момент добавляет армии больше всего ценности за свою взвешенную цену, на все доступные деньги, и затем оценка повторяется. Ресурс, которого игроку не хватает, делает существ, которым он нужен, менее привлекательными, но не может отнять больше 75% их ценности. **[code]**

### Выигрыш от добавления отряда

`0x42c830`, величина из шага 3.

```
выигрыш = AI Value × купленное количество
```

с такими поправками:

- **Скорость на карте.** Если существо медленнее самого медленного отряда в армии, применяется слагаемое из [таблицы движения по суше](../adventure/#на-суше), умноженное на `AI Value армии + 500`: медленное пополнение, которое сократит дневной ход героя, стоит меньше. **[слагаемое прочитано; то, что оно уменьшает выигрыш, является inferred]**
- **Уже есть в армии.** Если в армии есть отряд этого существа, новые существа присоединяются к нему и выигрыш остаётся как есть.
- **Свободный слот.** Иначе занимается свободный слот, если в армии занято меньше шести слотов (или вызывающий код разрешает седьмой).
- **Правило смешивания.** Существу другого мировоззрения, которое испортило бы армии мораль, свободный слот не даётся, когда отряд мал: когда его десятикратная ценность не превышает ценности армии, в которую он попадает.
- **Свободного слота нет.** Функция выбирает отряд, который придётся выгнать (`0x42c690`), и выигрыш уменьшается на его `AI Value × количество`. Если выгнать некого, выигрыш равен 0.

### Какой отряд выгоняется

`0x42c690`. Из отрядов, уже находящихся в армии, заменяется тот, у которого **наименьшая суммарная `AI Value × количество`**, с двумя защитами для стрелков:

- если в армии ровно один отряд стрелков, его не выгоняют никогда;
- когда вызывающий код просит сохранить стрелковую силу, а в армии четыре или больше отрядов стрелков, выгнать можно только отряд стрелков.

Если покупка нарушила бы правило смешивания выше, кандидатами становятся только отряды «чужого» мировоззрения.

## Обмен на Рынке

Компьютерный игрок не торгует ради выгоды и не выравнивает запасы. Он меняет ресурсы только **чтобы завершить конкретную покупку**, изнутри функции оценки `0x42a150`.

1. **Повод.** При оценке цепочки построек ресурс считается блокирующим, когда запас меньше стоимости и у игрока **нет дохода** этого ресурса. Если доход есть, ИИ просто ждёт.
2. **Что можно продать** (`0x42a2b0`). Для каждого другого ресурса: `излишек = запас − стоимость планируемой покупки − подушка`, где подушка — количество, уже зарезервированное под другие покупки, но не меньше 20. Излишек дополнительно ограничен избытком из [весов ресурсов](../ai-adventure/#сколько-стоят-ресурсы) (`есть − нужно`). Ресурс без положительного излишка не продаётся.
3. **Где** (`0x42a580`). Нужен хотя бы один Рынок. Число Рынков, до 10, задаёт курс обмена так же, как у человека. Рынок, который игрок мог бы построить сегодня, тоже считается, если у него есть доход золота.
4. Если чего-то не хватает и что-то лишнее есть, функция продаёт излишки, чтобы закрыть нехватку. Если нехватку закрыть не удаётся, цель покупки на этот ход отбрасывается.

В каком порядке продаются излишки, не прочитано. **[code]**

## Подарки союзникам

`0x429110`, вызывается в конце экономической части хода для каждого игрока той же команды: сначала союзники-компьютеры, затем союзники-люди. Выполняется, только если у дарителя есть город с **Рынком**.

Для каждого ресурса:

```
избыток = есть − нужно                     те же величины, что в весах ресурсов
подарок = min(избыток, (мой запас − запас союзника) / 2)
оставить себе не меньше 10000 золота или 20 единиц любого другого ресурса
вычесть зарезервированное под собственные покупки
отменить подарок, если он меньше 1000 золота или меньше 5 единиц другого ресурса
отменить подарок, если он меньше 5 × того, что у союзника уже есть
```

- Последняя строка означает, что подарки идут только союзнику, у которого этот ресурс почти кончился: количество должно быть не меньше пятикратного текущего запаса союзника.
- Союзнику-**компьютеру** подарок дополнительно ограничен тем, чего ему не хватает (`нужно − есть`, предварительно пересчитанными для него).
- Союзнику-**человеку** количество отправляется как посчитано, и показывается сообщение.

## Когда герой заходит в свой город

`0x5253d0` выполняется, когда герой ИИ входит в город своего игрока:

- Если герой несёт Грааль, а в городе его нет, строится здание Грааля.
- В армию героя нанимаются существа (`0x525200`, `0x42ba60`). На высокой сложности и выше, если город сегодня ещё не строил, функция может ещё и построить то одно жилище (постройки 30–43), которое прямо сейчас сильнее всего усилит армию этого героя.
- Для гостящего героя строится **уровень Гильдии магов** (`0x42beb0`). Следующий уровень строится, когда выполнено всё сразу:
  - гильдия ниже 5-го уровня и ниже `уровень Мудрости героя + 2`, то есть герою без Мудрости гильдия строится до 2-го уровня, с базовой до 3-го, с продвинутой до 4-го, с экспертной до 5-го;
  - у героя больше 2 Силы магии и больше 2 Знания; для первого уровня это не требуется, если у героя нет двух определённых базовых заклинаний;
  - ни в одном другом городе игрока нет более высокой гильдии, которой этот герой ещё может пользоваться и которую можно было бы достроить вместо этой;
  - игрок может заплатить и город сегодня ещё не строил.

  Так Гильдии магов строятся и помимо роли предпосылок: они идут за героями, которые могут ими пользоваться.
- Если сценарий выигрывается удержанием определённого города, а этот герой не сильнейший у игрока, он останавливается там и **оставляет свою армию в гарнизоне этого города** (`0x525200`). Выше лёгкой сложности, при двух и более героях, и только когда на городе нет отметки угрозы.
- В Сопряжении с **Университетом магии** герой учит те предлагаемые навыки, которые того стоят (`0x524ed0`): у него должно быть меньше восьми навыков, у игрока не меньше 2000 золота, а каждый навык оценивается так же, как в разделе [выбор при повышении уровня](../ai-adventure/#выбор-при-повышении-уровня).
- Покупается Книга заклинаний за 500 золота, если в городе есть Гильдия магов, а книги у героя нет.
- Существа в армии героя улучшаются там, где есть улучшенное жилище и игрок может заплатить.
- Постройка, дающая навык, строится на месте, если для этого героя она стоит больше, чем обходится по весам ресурсов:

  | Город | Постройка | С чем сравнивается |
  |---|---|---|
  | Башня | особая 23 (+1 Знание) | ценность очка Знания для героя |
  | Инферно | особая 23 (+1 Сила магии) | ценность очка Силы магии для героя |
  | Темница | особая 23 (+1000 опыта) | `1000 ×` ценность одного очка опыта для героя |
  | Цитадель | особая 23 (+1 Атака) | опыт до следующего уровня героя × ценность одного очка опыта |
  | Крепость | особая 17 (+1 Защита) | то же |
  | Сопряжение | особая 21 (Университет магии) | функция оценки навыков |

- Выше лёгкой сложности герой покупает **боевую машину** города, если у него её нет (`0x525ca0`): ту, что продаёт Кузница этого города, а в Цитадели ещё и Баллисту из Двора баллист. Машина должна подходить герою и быть полностью по карману. Если самой Кузницы нет, но её можно построить сегодня, функция сначала строит её, а затем покупает.
- Выше лёгкой сложности герой гарнизона и гостящий герой **обмениваются артефактами** (`0x433fe0`, выполняется по разу в каждую сторону). Для каждого надетого артефакта функция снимает его, проверяет, вырастет ли суммарная ценность артефактов другого героя больше, чем упадёт у этого (`0x433e20`, `0x433bb0`), и либо передаёт артефакт, либо возвращает на место. Артефакты из рюкзака передаются, если другой герой может ими воспользоваться.

## Пока не разобрано

- Подробности ценности улучшенных жилищ и зданий прироста.
- Общее деление армий между гарнизоном города и героями; прочитан только описанный выше случай города из условия победы.
- Торговцы артефактами в городах (объект «Чёрный рынок» описан в разделе [ценности объектов](../ai-adventure/#ценности-объектов-которые-удалось-прочитать)) и порядок, в котором на Рынке продаются излишки.
- Отметка угрозы описана в разделе [как город получает отметку угрозы](../ai-adventure/#как-город-получает-отметку-угрозы); тот же проход закупает экстренный гарнизон до выбора построек.

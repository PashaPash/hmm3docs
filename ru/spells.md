# Магия

Из `SPTRAITS.TXT` **[data]**. Для ударных заклинаний урон = `× Сила` × сила магии + значение эффекта для уровня школы у заклинателя. Последний столбец — ценность заклинания, которую читает ИИ при выборе, что колдовать.

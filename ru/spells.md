# Магия

Из `SPTRAITS.TXT` **[data]**. Для ударных заклинаний урон = `× Сила` × сила магии + значение эффекта для уровня школы у заклинателя. Последний столбец — ценность заклинания, которую читает ИИ при выборе, что колдовать.

> **HotA 1.8.1:** у Стены огня, Армагеддона, четырёх Защит и двух призывов элементалей другие числа; см. [отличия HotA: заклинания](../hota/#заклинания).

Связанное: [какое заклинание колдует герой ИИ](../ai-battle/#заклинания-героя), [существа-заклинатели](../ai-battle/#существа-заклинатели), [стоимость шага при Полёте и Хождении по воде](../adventure/#стоимость-шага).

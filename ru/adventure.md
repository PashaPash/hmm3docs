## Очки движения в день

`0x4e4990`.

### На суше

```
очки = таблица[скорость самого медленного существа] × (1 + Логистика) + фиксированные прибавки
```

{% include movement.html lang="ru" %}

Из `MOVEMENT.TXT` **[data]**. Для скоростей ниже 3 та же таблица продолжается вниз (1300, 1360, 1430).

- Берётся **базовая** скорость существа из таблицы существ. Если герой — специалист по этому существу или по существу, в которое оно улучшается, этот отряд считается на 1 быстрее.
- Логистика: 10% / 20% / 30% (таблица `0x63ea68`). Специалист по Логистике умножает процент на `1 + 0.05 × уровень героя`.
- Фиксированные прибавки добавляются после умножения, то есть Логистика их не увеличивает: артефакт 98 (Сапоги скорости) +600, артефакт 70 (Перчатки всадника) +300, посещение Конюшен +400. Величины взяты из столбца бонусов `MOVEMENT.TXT`.
- Пустая армия использует верх таблицы.

### На море

На корабле скорость существ не учитывается.

```
очки = основа по Навигации + прибавка специалиста + фиксированные прибавки
```

| Навигация | нет | Базовая | Продвинутая | Эксперт |
|---|---|---|---|---|
| Основа | 1500 | 2250 | 3000 | 3750 |

- Специалист по Навигации добавляет `уровень героя × 1500 / 20`, то есть 75 очков за уровень.
- Фиксированные прибавки: +500 за каждый Маяк на карте, отмеченный флагом игрока **[inferred: считающая функция не прочитана]**, +500 за каждый город Замок игрока с постройкой Маяк, +500 за артефакт 123 (Шляпа морского капитана), +1000 за артефакт 71 (Ожерелье морского провидения).

## Стоимость шага

`0x4b1740`. Стоимость выражена в тех же очках движения.

| Местность | Без Поиска пути | Базовый | Продвинутый | Эксперт |
|---|---|---|---|---|
| Грязь, трава, подземелье, лава, вода | 100 | 100 | 100 | 100 |
| Камни | 125 | 100 | 100 | 100 |
| Песок, снег | 150 | 125 | 100 | 100 |
| Болото | 175 | 150 | 125 | 100 |
| Грунтовая дорога | 75 | 75 | 75 | 75 |
| Гравийная дорога | 65 | 65 | 65 | 65 |
| Мощёная дорога | 50 | 50 | 50 | 50 |

Таблица `0x63e510`.

- **Дорога** полностью заменяет стоимость местности; Поиск пути дороги не удешевляет.
- **Родная местность**: если местность клетки родная для всех существ армии, шаг стоит 100 при любой местности, кроме одного особого типа почвы.
- **Кочевники** в армии делают песок равным по стоимости грязи.
- **Диагональный** шаг стоит ×1.414.
- **Правило последнего шага**: если у героя хватает очков на прямую стоимость клетки, но не хватает на диагональную, диагональный шаг оплачивается по прямой стоимости. Герой поэтому всегда может закончить диагональный ход, который мог бы сделать по прямой.
- **Полёт** и **Хождение по воде** берут фиксированную стоимость за шаг по уровню заклинания: 140 / 140 / 120 / 100 для «нет» / базового / продвинутого / эксперта (таблица `0x6778ac`). Артефакт 72 (Крылья ангела) и артефакт 90 (Сапоги левитации) работают как заклинание уровня эксперта. При полёте над обычной проходимой сушей берётся меньшая из стоимости местности и стоимости полёта.
- На воде один особый тип поверхности снижает стоимость до двух третей.
